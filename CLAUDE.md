# CLAUDE.md — правила работы в студии «Что если, Гоша?»

## Общение
- Отвечать по-русски, кратко и по делу.
- Перед крупными изменениями (переписывание движка, сцен, звуковой схемы) — сначала согласовать план.

## Правила канала
- Формат: вертикальные шортсы для TikTok / YouTube Shorts, 1080×1920, 30 fps.
- Каждый ролик начинается с фразы **«Что если Гоша …»**.
- Длина ролика 1:00–1:10.
- Гоша — единственный постоянный персонаж. Второстепенные герои безымянные и появляются один раз.
- Голос: ElevenLabs, voice ID `DhwIuljOm695yhWY4OpF` (Ivan – Warm Russian Conversational).
- Звук: голос, тихая музыка (0.11), SFX по действию + свуши (0.65, с даккингом под голос), loudnorm −14 LUFS.

## Структура репозитория
| Папка | Что внутри |
|---|---|
| `gosha-sheet/` | Модельный лист Гоши: `doodle.js` (рисовалка персонажа), эмоции, развороты |
| `avatar/` | Аватарка канала |
| `fly-short/` | Первый ролик (муха): `render/engine.js` (2.5D-движок на canvas), сцены, субтитры, инструменты |
| `batch/` | Научные ролики |
| `life/` | Жизненные ролики |
| `sfx/` | Синтез SFX (`sfx.py`), метки (`mix.py`, `cues/`), даккинг (`duck.py`), пересборка (`remix_all.sh`) |

Внутри проекта: `scripts/` или `*.txt` — сценарии, `voice/*.mp3` — озвучка, `render/v_*.js` — шоты и камера, `render/cap_*.js` — субтитры, `tools/` — скрипты.

## Пайплайн сборки ролика
1. Озвучка ElevenLabs → `voice/NAME.mp3`.
2. Тайминги слов: `tools/align_segs.py`.
3. Проверка кадров: `python3 tools/frames.py still NAME 1.0 5.0 12.0` → `checks/`.
4. Видео без звука: `python3 tools/frames.py video NAME` → `out/_NAME_v.mp4`.
5. Голос и музыка: `tools/add_voice.py`.
6. SFX и финальный звук: `sfx/remix_all.sh` (в скриптах захардкожены пути `/home/claude/...` — поправить под текущее окружение).

Музыка генерируется процедурно (`fly-short/tools/music.mjs`).

## Правила работы с кодом
- Гошу рисовать только через `gosha-sheet/doodle.js` — не создавать собственные версии персонажа.
- Новый ролик делать по образцу существующих (`batch/`, `life/`) и переиспользовать `fly-short/render/engine.js`.
- Перед полным рендером проверять ключевые кадры (`frames.py still`) и показывать их пользователю.
- Не менять голос, уровни громкости и loudnorm без явной просьбы.
- Не коммитить `*.mp4`, `*.wav`, `out/`, `checks/`, `final/` (они в `.gitignore`).
