# Сайт «Роллеты и ворота»

Простой сайт-каталог без сервера: обычные HTML-страницы.

## Как открыть
Откройте файл `index.html` двойным щелчком — сайт откроется в браузере.

## Страницы
- `index.html` — главная (баннер, разделы каталога, преимущества, этапы работы, форма заявки)
- `catalog.html` — каталог «Роллеты для дверей и окон» (фильтры, сортировка, карточки)
- `product.html?id=1` — страница товара (цвета, калькулятор цены, характеристики, похожие товары)
- `contacts.html` — контакты и форма

## Как поменять данные
Всё в одном файле — `js/data.js`:
- `COMPANY` — название, телефон, почта, адрес, часы работы;
- `PRODUCTS` — товары и цены (цена за 1 м²);
- `CATEGORIES` — разделы на главной.

Чтобы поставить настоящее фото товара, положите его в папку `img/` и добавьте товару поле `photo: "img/имя-файла.jpg"`.

## Что ещё не сделано
- Заявки пока **никуда не отправляются** (показывается только «Спасибо»). Нужно подключить отправку на почту или в Telegram.
- Вместо карты — заглушка (можно вставить код из конструктора Яндекс.Карт).
- Цены и тексты — примерные, их нужно заменить.
- Сайт нужно разместить на хостинге (например, бесплатно на GitHub Pages / Netlify) и привязать домен.
