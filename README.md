# What if, Fobbin? — студия

Исходники анимационных шортсов «What if Fobbin…» (TikTok / YouTube Shorts, 1080×1920, 30 fps).

## Правила канала
- Аудитория — США. Ролики на английском.
- Каждый ролик начинается с фразы **«What if Fobbin …»**.
- Длина ролика 1:00–1:10.
- Fobbin — единственный постоянный персонаж (внешность — модельный лист `character/sheet.html`). Второстепенные герои безымянные и появляются один раз.
- Голос: английский голос ElevenLabs — ещё не выбран.
- Звук: голос, тихая музыка (0.11), SFX по действию + свуши (0.65, с даккингом под голос), loudnorm −14 LUFS.

### Как делать ролик
1. **Крючок в первом кадре.** С первой секунды — действие и опасность (мухобойка летит в лицо, Солнце гаснет). Титр «WHAT IF…» не дольше 1 с, поверх действия, а не вместо него.
2. **Текст на экране — с «YOU»**: «WHAT IF YOU SAW LIKE A FLY?». Голосом — «What if Fobbin …», быстро, без паузы после имени.
3. **Высокая ставка в каждом ролике**: угроза телу, жизни, планете, рекорд или знаменитый миф. Мягкий юмор — только в концовке.
4. **История, а не лекция.** Никаких «правило первое, второе». Формат: Fobbin делает → последствия → один вывод → смешной поворот.
5. **Американские реалии**: мили, футы, °F, американские места и предметы (Empire State, мухобойка, бейсбол).
6. **Имя Fobbin — безопасность.** Никогда не делать Fobbin иммигрантом или «новеньким из другой страны», не шутить про лодки и акцент. Имя произносится «FOB-in».
7. **Хронометраж 1:00–1:10** набирать событиями и ставками, а не пересказом.

### Что измерять
- YouTube Shorts: «Viewed vs swiped away» (сила крючка), средний % просмотра, повторы.
- TikTok: удержание на 2-й секунде, среднее время просмотра, досмотры.
- Везде: репосты и сохранения на 1000 просмотров, комментарии (о теме или об имени?), подписки на 1000 просмотров.
- Через 30 дней оставить 2–3 рубрики-победителя и делать их сериями.

## Папки
| Папка | Что внутри |
|---|---|
| `us/scripts/` | Сценарии: крючок первого кадра, текст на экране, озвучка EN, перевод RU, факты для проверки |
| `us/render/` | Сборка кадров: `engine.js` (2.5D-движок на canvas), `doodle.js` (персонаж), `sets.js` (декорации), `common.js` (кадр, титр, субтитры); на каждый ролик — `v_NAME.js` (шоты), `text_NAME.js` (надписи en/ru), `cap_NAME.js` (субтитры), `index_NAME.html` |
| `us/tools/` | `align.py` (субтитры по голосу), `check.py` (автопроверка), `frames.py` (кадры и видео), `music.mjs` (музыка) |
| `character/` | Модельный лист Fobbin: `sheet.html` → `fobbin_sheet.png` (`python3 render.py sheet.html fobbin_sheet.png 2400 1720`), рисовалка персонажа `doodle.js` |
| `sfx/` | Синтез звуковых эффектов (`sfx.py`), авторасстановка (`mix.py`), приглушение под голос (`duck.py`) |
| `tools/` | `yt_search.py` — поиск трендов на американском YouTube |
| `avatar/` | Аватарка канала: `avatar.html` → `fobbin_avatar.png` |

## Как собрать ролик
Нужны Python 3 (numpy, scipy, pillow, playwright), Chromium для Playwright, ffmpeg, Node 22. Все команды — из папки `us/`.
Если Playwright не находит свой Chromium, укажи путь к нему: `CHROMIUM_PATH=/путь/к/chrome`.

1. **Сценарий.** `scripts/NAME.md` — по образцу готовых.
2. **Проверка до озвучки.** `python3 tools/check.py NAME` — оценит длину по числу слов (норма 1:00–1:10).
3. **Озвучка.** Сгенерировать в ElevenLabs и положить в `voice/NAME.mp3`.
4. **Субтитры.** `python3 tools/align.py NAME` — сам найдёт паузы в голосе и создаст `render/cap_NAME.js`.
5. **Шоты.** `render/v_NAME.js` + надписи в `render/text_NAME.js` + `render/index_NAME.html` (образец — `01_sun`).
6. **Проверка.** `python3 tools/check.py NAME` — длина голоса, титр ≤1 с, надписи без кириллицы и без пропущенных ключей, кадры крючка 0.0/0.5/1.0/2.0 с в `checks/`.
7. **Музыка.** `node tools/music.mjs 70 playful` → `voice/music.wav`.
8. **Видео.** `python3 tools/frames.py video NAME` → `out/NAME.mp4` (голос + музыка).

Готовые mp4 и wav в репозиторий не входят.
