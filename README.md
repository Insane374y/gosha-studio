# What if, Fobbin? — студия

Исходники анимационных шортсов «What if Fobbin…» (TikTok / YouTube Shorts, 1080×1920, 30 fps).

## Правила канала
- Аудитория — США. Ролики на английском.
- Каждый ролик начинается с фразы **«What if Fobbin …»**.
- Длина ролика **строго не меньше 1:00**, средняя — **1:10–1:15** (ориентир для сценария, не жёсткий предел).
- Субтитры: белые, звучащее слово вспыхивает жёлтым; крючок (первая фраза до «?») копится на экране и держится до конца фразы (`us/render/common.js`, drawCaptions).
- Скорость озвучки — всегда **×1.17**; длину под 1:15 скоростью не подгоняем.
- **Сценарии пишет только агент `fobbin-scenarist`** (`.claude/agents/fobbin-scenarist.md`) — он за них отвечает. Основной чат передаёт ему тему и найденные факты, проверяет готовый файл и делает по нему ролик.
- Озвучка Lumean — полностью сама: заказ → скачивание (s3.lumean.app разрешён) → ×1.17 → субтитры. **Автор дал постоянное разрешение (31.10.2026): озвучивать в Lumean без отдельного спроса**, если в «Озвучке (EN)» не больше ~200 слов. Длиннее — сначала спросить.
- Fobbin — единственный постоянный персонаж (внешность — модельный лист `character/sheet.html`). Второстепенные герои безымянные и появляются один раз.
- Голос: ElevenLabs через Lumean (`us/tools/voice.py`, ключ в секрете `LUMEAN_API_KEY`). Голос канала: **Brian McManaman - Articulate, Mature** (ElevenLabs, американский), voice_id `7JKSHBXJND62BxGKvDdb`.
- Звук: голос + тихая музыка + звуковые эффекты для погружения — без перебора:
  - **свуш на каждую вылетающую плашку** и мягкий вжух на склейках (ставятся автоматически);
  - **сюжетные звуки** по действию: скрип двери, шаги, ветер, щелчки и т. п. (`us/sfx/NAME.py`);
  - эффекты тише голоса и автоматически приглушаются под ним; итог — loudnorm −14 LUFS.

### Как делать ролик
1. **Крючок в первом кадре.** С первой секунды — действие и опасность (мухобойка летит в лицо, Солнце гаснет). Титр «WHAT IF…» не дольше 1 с, поверх действия, а не вместо него.
2. **Текст на экране — с «YOU»**: «WHAT IF YOU SAW LIKE A FLY?». Голосом — «What if Fobbin …», быстро, без паузы после имени.
3. **Высокая ставка в каждом ролике**: угроза телу, жизни, планете, рекорд или знаменитый миф. Подача максимально реалистичная и жёсткая: показываем, что было бы на самом деле, включая неприятные повороты, без смягчений и без юмора в концовке.
4. **История, а не лекция.** Никаких «правило первое, второе». Формат: Fobbin делает → последствия → один вывод → реалистичный жёсткий финал, без спасительного или смешного переворота. Не приводим истории реальных людей (ни по имени, ни как «это было на самом деле») — всё происходит только с Fobbin, опора на науку и факты о мире.
5. **Американские реалии**: мили, футы, °F, американские места и предметы (Empire State, мухобойка, бейсбол).
6. **Имя Fobbin — безопасность.** Никогда не делать Fobbin иммигрантом или «новеньким из другой страны», не шутить про лодки и акцент. Имя произносится «FOB-in».
7. **Мягкое свечение.** Всё, что излучает свет — солнце, лампы, фонари, окна, фонарик, экраны, — светится мягким ореолом; в воздухе редкие тёплые пылинки. Персонаж рядом со светом получает **контурный свет** с его стороны и его цветом (окно — холодный белый, батарея/лампа — тёплый), чтобы вписываться в сцену. Делается автоматически (`us/render/common.js` → `bloom`, `motes`, `rimLight`): лампа/фонарь — `box(..., { glow })`, картинка окна — `painter.glow`, любая точка — `emitGlow(x, y, r, цвет)`.
8. **Инфографика в нужные моменты.** Когда голос называет число, сравнение или процесс — поверх сцены выскакивает карточка: график (`chartLine`), столбики (`chartBars`), счётчик (`infoCounter`), шкала (`infoMeter`) — `us/render/info.js`, `infoCard(...)`. Без перебора: 2–4 карточки на шортс.
9. **Хронометраж: не меньше 1:00, цель 1:10–1:15** (≈185–200 слов озвучки). Набирать событиями и ставками, а не пересказом.

### Что измерять
- YouTube Shorts: «Viewed vs swiped away» (сила крючка), средний % просмотра, повторы.
- TikTok: удержание на 2-й секунде, среднее время просмотра, досмотры.
- Везде: репосты и сохранения на 1000 просмотров, комментарии (о теме или об имени?), подписки на 1000 просмотров.
- Через 30 дней оставить 2–3 рубрики-победителя и делать их сериями.

## Как заказать ролик одной фразой
Автор пишет в новом чате Claude Code: «Сделай ролик: <тема>» (или вставляет готовый сценарий и пишет «Сделай ролик по этому сценарию»).
Дальше без вопросов: агент `fobbin-scenarist` пишет сценарий в `us/scripts/` (если его нет) → озвучка Lumean ×1.17 → субтитры → декорации и ролик → готовый `us/out/What_if_Fobbin_<name>.mp4` отправить автору → коммит и пуш.

## Как собрать ролик
Нужны Python 3 (numpy, scipy, pillow, playwright), Chromium для Playwright, ffmpeg, Node 22. Все команды — из папки `us/`.
Если Playwright не находит свой Chromium, укажи путь к нему: `CHROMIUM_PATH=/путь/к/chrome`.

1. **Сценарий.** `scripts/NAME.md` — по образцу готовых.
2. **Проверка до озвучки.** `python3 tools/check.py NAME` — оценит длину по числу слов (не меньше 1:00, цель 1:10–1:15).
3. **Озвучка.** `python3 tools/voice.py NAME` — озвучит раздел «Озвучка (EN)» через Lumean и ускорит голос ×1.17 (всегда; под длину ролика не подгоняем — 1:16–1:17 тоже нормально). Один раз до этого: `python3 tools/voice.py voices` (пробы голосов) и `python3 tools/voice.py setup VOICE_ID` (шаблон с выбранным голосом).
4. **Субтитры.** `python3 tools/align.py NAME` — сам найдёт паузы в голосе и создаст `render/cap_NAME.js`.
5. **Шоты.** `render/v_NAME.js` + надписи в `render/text_NAME.js` + `render/index_NAME.html` (образец — `01_sun`).
6. **Проверка.** `python3 tools/check.py NAME` — длина голоса, титр ≤1 с, надписи без кириллицы и без пропущенных ключей, кадры крючка 0.0/0.5/1.0/2.0 с в `checks/`.
7. **Сюжетные звуки.** `sfx/NAME.py` — по образцу `01_sun.py`: 10–15 звуков на ролик, только там, где на экране есть действие.
8. **Видео.** `python3 tools/frames.py video NAME` → `out/NAME.mp4`. Он сам вызовет `tools/sound.py`: свуши на плашки и склейки, сюжетные звуки, музыка нужного настроения, приглушение под голос. Только пересвести звук без перерендера: `python3 tools/sound.py NAME`.

Готовые mp4 и wav в репозиторий не входят.
