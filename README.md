# What if, Fobbin? — студия

Исходники анимационных шортсов «What if Fobbin…» (TikTok / YouTube Shorts, 1080×1920, 30 fps).

## Правила канала
- Аудитория — США. Ролики на английском.
- Каждый ролик начинается с фразы **«What if Fobbin …»**.
- Длина ролика 1:00–1:10.
- Fobbin — единственный постоянный персонаж. Раньше его звали Гоша; образ тот же (модельный лист в `gosha-sheet/`), поменялось только имя. Второстепенные герои безымянные и появляются один раз.
- Голос: английский голос ElevenLabs — ещё не выбран.
- Звук: голос, тихая музыка (0.11), SFX по действию + свуши (0.65, с даккингом под голос), loudnorm −14 LUFS.

### Как делать ролик для США
1. **Крючок в первом кадре.** С первой секунды — действие и опасность (мухобойка летит в лицо, Солнце гаснет). Титр «WHAT IF…» не дольше 1 с, поверх действия, а не вместо него.
2. **Текст на экране — с «YOU»**: «WHAT IF YOU SAW LIKE A FLY?». Голосом — «What if Fobbin …», быстро, без паузы после имени.
3. **Высокая ставка в каждом ролике**: угроза телу, жизни, планете, рекорд или знаменитый миф. Мягкий юмор — только в концовке.
4. **История, а не лекция.** Никаких «правило первое, второе». Формат: Fobbin делает → последствия → один вывод → смешной поворот.
5. **Американские реалии**: мили, футы, °F, мухобойка вместо тапка, Empire State вместо «пятого этажа».
6. **Кот Biscuit** — сквозная шутка: появляется в последние 3 секунды каждого ролика.
7. **Имя Fobbin — безопасность.** Никогда не делать Fobbin иммигрантом или «новеньким из другой страны», не шутить про лодки и акцент. Имя произносится «FOB-in».
8. **Хронометраж 1:00–1:10** набирать событиями и ставками, а не пересказом.

Сценарии для США лежат в `us/scripts/`: каждый с крючком первого кадра, текстом на экране, озвучкой на английском, переводом и фактами для проверки.

### Что измерять
- YouTube Shorts: «Viewed vs swiped away» (сила крючка), средний % просмотра, повторы.
- TikTok: удержание на 2-й секунде, среднее время просмотра, досмотры.
- Везде: репосты и сохранения на 1000 просмотров, комментарии (о теме или об имени?), подписки на 1000 просмотров.
- Через 30 дней оставить 2–3 рубрики-победителя и делать их сериями.

## Архив: русская версия «Что если, Гоша?»
Ролики в `fly-short/`, `batch/` и `life/` сделаны для русскоязычной аудитории: персонаж там зовётся Гоша, начало — «Что если Гоша …».
Голос: ElevenLabs, voice ID `DhwIuljOm695yhWY4OpF` (Ivan – Warm Russian Conversational).

## Папки
| Папка | Что внутри |
|---|---|
| `gosha-sheet/` | Модельный лист Гоши: `doodle.js` (рисовалка персонажа), эмоции, развороты |
| `avatar/` | Аватарка канала |
| `fly-short/` | Первый ролик (муха): `render/engine.js` (2.5D-движок на canvas), сцены, субтитры, инструменты |
| `batch/` | 6 научных роликов (хамелеон, летучая мышь, солнце, сны, муравей, Земля) |
| `life/` | 5 жизненных роликов (родители девушки, работа, заграница, общага, признание) |
| `us/` | Сценарии для американской версии «What if, Fobbin?» |
| `sfx/` | Синтез звуковых эффектов (`sfx.py`), авто- и ручные метки (`mix.py`, `cues/`), даккинг (`duck.py`), пересборка всех роликов (`remix_all.sh`) |

В каждом проекте:
- `scripts/` или `*.txt`: сценарии;
- `voice/*.mp3`: озвучка;
- `render/v_*.js`: шоты и камера;
- `render/cap_*.js`: субтитры;
- `tools/`: скрипты.

## Как собрать ролик
Нужны Python 3 (numpy, scipy, pillow, playwright), Chromium для Playwright, ffmpeg, Node 22.

1. **Озвучка.** Сгенерировать в ElevenLabs и положить в `voice/NAME.mp3`.
2. **Тайминги слов.** Запустить `tools/align_segs.py`: он разбивает голос по паузам и привязывает слова к субтитрам.
3. **Проверка кадров.** `python3 tools/frames.py still NAME 1.0 5.0 12.0` сохранит отдельные кадры в `checks/`.
4. **Видео без звука.** `python3 tools/frames.py video NAME` соберёт `out/_NAME_v.mp4`.
5. **Голос и музыка.** `tools/add_voice.py`.
6. **Эффекты и финальный звук.** `sfx/remix_all.sh`. Перед запуском поправь пути `/home/claude/...` на свои.

Музыка генерируется процедурно (`fly-short/tools/music.mjs`). Готовые mp4 и wav в репозиторий не входят.
